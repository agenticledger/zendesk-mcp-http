How to connect

This server is broker-first: the MCP process holds zero Zendesk secrets. Auth is per-connection OAuth — you supply your own Zendesk subdomain and OAuth client id/secret once through a broker-hosted connect page, and the broker stores and refreshes the token for you. If you call a tool before connecting, the server replies with a structured connection_required message (never an error) pointing you to the connect page.

  1. Point your MCP client at https://zendeskmcp.agenticledger.ai/mcp (label it Connect via HTTP).
  2. On first call, open the broker-hosted connect page at https://zendeskmcp.agenticledger.ai/ and enter your Zendesk subdomain plus your own OAuth client_id / client_secret.
  3. Approve the OAuth grant in Zendesk. The broker exchanges and stores the token — all 101 tools go live for your principal.
Escape hatch: for direct or testing use you may pass a raw Authorization: Bearer <token> together with an X-Zendesk-Base-Url header instead of connecting through the broker. Every tool targets {baseUrl}/api/v2.
